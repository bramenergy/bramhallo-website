Newsletter Digest — Privacy Policy

Last updated: September 3, 2026

Newsletter Digest is a personal tool built and used by a single person (Bram Hallo). It is not offered as a public product or service to other users. This page exists to satisfy Google's OAuth verification requirements for the Gmail API access the tool uses.

What the app accesses

The app connects, via read-only OAuth, to exactly one dedicated Gmail mailbox set up specifically for this tool — never a personal inbox. It can only read email content from that mailbox; it cannot send, delete, modify, or access any other mailbox.

What happens to that data

  • Email content from the dedicated mailbox is sent to Anthropic's Claude API to be summarized into short "topic cards."
  • Those summaries, and a copy of the relevant original email text, are stored in a private database used only by this app.
  • If a topic is manually filed into a knowledge base, its content is written to a private GitHub repository used only by this app's owner.

What does not happen to that data

  • It is never sold, shared with advertisers, or used for any purpose beyond running this personal tool.
  • It is never made public — the database and GitHub repository it's stored in are both private.
  • No analytics or tracking is applied to the email content itself.

Third parties involved

Processing relies on Anthropic (Claude API), Google (Gmail API), Cloudflare (application hosting and database), and GitHub (private storage of filed content) — each solely as infrastructure providers for running this tool, under their own respective privacy and data-handling terms.
